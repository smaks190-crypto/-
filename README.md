**David Finance** — флагманское Android-приложение для ведения личного бюджета, контроля обязательств, накопления на финансовые цели и глубокого ИИ-аудита расходов. Выполнено в премиальной темной эстетике **Obsidian Neo-Bank** (в духе *Revolut Ultra*, *Т-Банк Pro* и *Wise Dark*) со встроенным харизматичным финансовым ревизором **Давидом Жабовым 🐸** на базе семейства моделей **Gemini Flash**.

---

## ✨ Ключевые возможности

### 1. 🏦 Дашборд «Obsidian Neo-Bank» и Умное бюджетирование
- **Hero-карточка баланса:** мгновенный расчет чистого сальдо периода, норма сбережений (*Savings Rate %*), сравнение расходов с прошлым месяцем (*MoM Delta %*) и динамика счетов.
- **Безопасный дневной лимит (Safe-to-Spend):** автоматический расчет суммы, которую можно потратить сегодня без риска выйти за месячный бюджет или уйти в кассовый разрыв.
- **Bento-матрица категорий с лимитами:** 2-колоночная сетка категорий расходов с индивидуальными прогресс-барами лимитов и цветовой индикацией перерасхода (`Emerald` → `Amber` → `Rose`).
- **Интерактивная аналитика:** графики динамики по дням и месяцам, кольцевая структура расходов и быстрый поиск по истории операций с группировкой по датам.

### 2. 🎙️ Живой голосовой ИИ-ввод (Gemini Live Style) и 0ms семантический парсер
- **Потоковое распознавание речи в реальном времени:** живая волна голоса с мгновенным отображением распознаваемых слов на экране (как в приложении Gemini).
- **Мультиоперационный ИИ-парсинг:** возможность надиктовать сразу несколько трат и доходов в одной фразе (*«Кофе 300 рублей, такси 650 и пришла премия 25 тысяч»*) с автоматическим разбором на карточки.
- **Гибридный движок категоризации:** мгновенный локальный семантический детектор (`0ms`) + интеллектуальный разбор через `gemini-3.5-flash` (с резервным переключением на `gemini-3.8-flash`).

### 3. 🐸 ИИ-аудитор «Давид Жабов» (Чат, Прожарка и Челленджи)
- **Персональный финансовый ревизор:** анализирует реальные транзакции, цели и долги из локальной БД Room и дает конкретные рекомендации с фирменной харизмой и юмором.
- **Режим «Прожарка трат»:** жесткий, но справедливый разбор импульсивных покупок, скрытых утечек бюджета (кофе, фастфуд, маркетплейсы, подписки) и вредных финансовых привычек.
- **Добавление операций прямо из чата:** если написать Давиду про покупку или доход, он сформирует интерактивную карточку предпросмотра операции с кнопкой подтверждения в 1 тап.
- **Геймификация и система рангов (XP):** 7 уровней финансовой эволюции (от *«Головастика с дырявым карманом»* до *«Изумрудного Магната Болота»*) и локальные достижения за финансовую дисциплину.

### 4. 🎯 Финансовые цели и копилки
- **Портфель накоплений:** сводная карточка общего капитала по всем копилкам и прогресс выполнения в процентах.
- **ИИ-прогноз темпа:** автоматический расчет рекомендуемого ежемесячного взноса для закрытия цели к концу года.
- **Пополнение в 1 тап:** быстрые пресет-чипсы (`+500 ₽`, `+1 000 ₽`, `+5 000 ₽`) прямо на карточке цели с автоматическим учетом взноса в расходах периода.

### 5. 🤝 Контроль долгов и займов
- **Раздельный учет «Я должен» / «Мне должны»:** наглядные карточки обязательств с историей частичных погашений и доборов.
- **Совет Давида (Метод снежного кома):** автоматическое выделение приоритетного долга с минимальным остатком для максимально быстрой разгрузки бюджета.
- **Прогресс-бар погашения:** визуальная шкала выплаченной доли по каждому займу.

### 6. 📊 Годовой аудит и безопасность данных
- **Годовая матрица:** сводка по всем 12 месяцам выбранного года (доход, расход, чистое сальдо, сбережения) и сравнительная гистограмма.
- **Банковский уровень приватности:** вход по **PIN-коду** и **биометрии (Отпечаток / Face Unlock)**, хранение ключей в `EncryptedSharedPreferences`.
- **Полный контроль над данными:** экспорт и импорт резервных копий базы данных (`JSON`), генерация отчетов, мультипрофили и встроенный **Демо-режим** для быстрого тест-драйва.

## 🎨 Дизайн-система «Obsidian Neo-Bank»

Интерфейс спроектирован специально для OLED-экранов с акцентом на читаемость финансовых метрик и управление одной рукой:
- **Палитра:** глубокий обсидиановый фон (`#06080E`), графитовые карточки (`#0E131F` / `#151C2C`), тонкие стеклянные микро-бордеры (`GlassBorder` / `GlassHighlight`) и семантические акценты (`Emerald #2CE59B`, `Indigo #6366F1`, `Rose #F43F5E`, `Sky #38BDF8`).
- **Типографика:**
  - `Space Grotesk` — геометрический гротеск с табличными пропорциями для всех сумм, балансов и процентов.
  - `Manrope` — чистый современный шрифт для навигации, аналитики и диалогов.
- **Эргономика:** плавающий стеклянный нижний док (**Floating Obsidian Glass Bottom Dock**) с центральной кнопкой живого голосового/ручного ввода.

## 🛠️ Технический стек и архитектура

| Слой | Технологии |
| :--- | :--- |
| **Язык** | 100% Kotlin |
| **UI-фреймворк** | Jetpack Compose + Material Design 3 (Edge-to-Edge, кастомные `Canvas`-графики и анимации `Animatable`) |
| **Архитектура** | MVVM + Clean Architecture, единый реактивный поток данных (`Kotlin Coroutines` + `StateFlow`) |
| **Локальная БД** | AndroidX Room (`TransactionEntity`, `CategoryEntity`, `GoalEntity`, `AccountEntity`, `NotificationEntity`, `ChatMessageEntity`) |
| **ИИ-ядро** | Google Gemini API (`gemini-3.8-flash` с fallback на `gemini-3.6-flash` для аудита и чата; `gemini-3.5-flash` для голосового парсинга) |
| **Безопасность** | `AndroidX Biometric`, `Security Crypto (EncryptedSharedPreferences)` |
| **Сборка и тесты** | Gradle (Kotlin DSL), Version Catalog (`libs.versions.toml`), KSP, JUnit 4 + Robolectric |

## 🚀 Быстрый старт и сборка

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/david-finance.git
cd david-finance
```

### 2. Настройка ключа Gemini API
Вы можете указать API-ключ Google AI Studio (Gemini) одним из двух способов:
1. **Прямо в приложении (рекомендуется для пользователей):** откройте чат с **🐸 Давидом AI** или меню настроек и вставьте ваш ключ Gemini API (он сохранится в зашифрованном хранилище устройства).
2. **Через конфигурацию сборки (для разработчиков):** скопируйте `.env.example` в `.env` и укажите `GEMINI_API_KEY=ваш_ключ`.

> 💡 **Примечание:** Приложение полностью работоспособно и без API-ключа — локальный семантический парсер (`0ms`), голосовой ввод, аналитика, цели и долги работают полностью офлайн.

### 3. Сборка APK
```bash
./gradlew :app:assembleDebug
```
Готовый установочный файл появится по пути:
`app/build/outputs/apk/debug/app-debug.apk`
